**Download:** on Windows, `deck-narrator-1.2.6-x64.msi` is the installer. It includes the voices, runs offline and replaces any older version, and 1.2.1 or newer offers this update on its own the next time it starts. With Chocolatey, run `choco upgrade deck-narrator`. On a Mac with Apple Silicon, use `deck-narrator-1.2.6-mac-arm64.dmg` and follow the [Mac guide](https://github.com/mikesimone/deck-narrator/blob/main/docs/MAC.md). `deck-narrator-windows-x64.zip` is the no-install Windows copy.

## New in 1.2.6

- **A Mac version.** A Mac app for Apple Silicon (M1 or newer, macOS 12 or later) that draws slides with Keynote and runs the voice on the Mac's graphics chip. It isn't registered with Apple, so the first time you open it, allow it once in System Settings. The [Mac guide](https://github.com/mikesimone/deck-narrator/blob/main/docs/MAC.md) shows each step with pictures.
- **Check pronunciation: one Use this settles a new word everywhere.** Saving a new word or company name to your dictionary now ticks and greys out every place it's listed, on every slide and in every capitalization (Zscaler, zscaler). Each spelling is saved, so all of them are said the same way. The top of the window counts how many words are still to check.
- **Common tech terms said right.** "AI" is now "ay eye" (it used to be "A ... I" with a pause, or "aye"), and API, AWS, JSON, SOC, CISO, OWASP, SASE, CASB, 2FA, PostgreSQL and about a dozen more are fixed too. Each fix was checked with the real voices. They apply to every deck, and a rule for the same word in your dictionary still wins.
- **Let an AI write your notes.** The best videos come from having an AI chatbot write the speaker notes and handle the pronunciations. A [new guide](https://github.com/mikesimone/deck-narrator/blob/main/docs/AI-NOTES.md) has a prompt you can copy and paste.
- **Shorter docs.** The README is now a short start page. Install steps for Windows, Mac and Linux, the user guide and the reference each have their own page, and the zip and the Mac app include them.
- **Tip jar.** Settings has a **Buy me a coffee** button. Deck Narrator stays free; a tip keeps it going.
