**Download:** `deck-narrator-1.2.5-x64.msi` is the installer: it includes the voices, runs offline and replaces any older version. (1.2.1 offers this update on its own the next time it starts.) `deck-narrator-windows-x64.zip` is the no-install copy.

## New in 1.2.5

- **Your own pronunciation dictionary, built as you go.** In **Check pronunciation**, **Use this** on a word the voice doesn't know, or would spell out letter by letter, now saves it in your dictionary. Every deck says it that way from then on, and it drops off the list. Words with more than one pronunciation (read, present) still get fixed in that slide's notes, because the right one depends on the sentence.
- **Your dictionary is used automatically.** It lives in `%APPDATA%\deck-narrator\pronunciations.txt`, and is created the first time you save a word. The window and the command line both use it without being asked, and the **Pronunciation** tab shows how many words it has, with an **Edit** button.
- **Settings window.** Things that rarely change have moved off the tabs into **Settings** (top right): pauses, empty slides, animations, temp files, which dictionary file to use, PowerPoint or LibreOffice, CPU or GPU, and the startup checks for new voices and updates. The main window keeps just the Deck, Voice, Pronunciation and Log tabs.
- **Command line:** `--add-word WORD PHONEMES` saves a word in the dictionary. Without `--pronunciations`, your personal dictionary is used if you have one. `DECK_NARRATOR_DICTIONARY` moves it.
