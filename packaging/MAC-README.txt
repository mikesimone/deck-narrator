Deck Narrator for Mac
=====================

1. Drag "Deck Narrator" onto the Applications folder in this window.

2. Open your Applications folder and double-click Deck Narrator.
   The first time, macOS says it "can't be opened" or "Apple could not verify" it.
   Click Done (not Move to Trash). This happens because the app isn't registered
   with Apple; it's built in public from github.com/mikesimone/deck-narrator.

3. Open System Settings > Privacy & Security, scroll down, and click
   "Open Anyway" next to Deck Narrator. Enter your Mac password if asked,
   then click Open Anyway again. You only do this once.

4. To draw the slides, Deck Narrator uses Keynote (free in the App Store).
   The first time, macOS asks whether Deck Narrator may control Keynote:
   click OK.

Step-by-step guide with pictures:
