deck-narrator, Windows standalone build
=======================================

(The installer, deck-narrator-<version>-x64.msi on the Releases page, is the easier way:
it includes the voices and adds a Start menu entry. This zip is the same program unpacked.)

Turns a PowerPoint deck's speaker notes into a voice-narrated MP4.

1. Slides are drawn with Microsoft PowerPoint if it's installed. Without PowerPoint,
   run install-dependencies.cmd in this folder once: it downloads and installs a
   minimal LibreOffice that leaves Office's file types alone. ffmpeg is included
   (in the ffmpeg folder), so there's nothing else to install.

2. Run it: double-click deck-narrator-gui.exe for the window, or from a terminal

     .\deck-narrator.exe C:\path\to\deck.pptx

   The video is written next to the deck (deck.mp4). The first run downloads the
   voice model (about 330 MB) into %USERPROFILE%\.cache\huggingface.

This build runs the voice on the CPU (no GPU needed; a 4-minute deck renders in under
a minute on an 8-core desktop CPU). For NVIDIA GPU speed, install from source instead:
see README.md, "Windows from source".

Full documentation: README.md in this folder, or the project page on GitHub.
